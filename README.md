# PiggieTV Android TV

This project is a native Android TV and Fire TV app for PiggieTV, built as a first-class Android app rather than a web-view wrapper.

## What this scaffold includes

- Native Android TV manifest targeting Leanback / Fire TV
- Kotlin entry activity and a simple TV-friendly home screen
- Material/Leanback-friendly structure for connecting to Jellyfin
- A place to integrate the PiggieTV web experience as a future native UI layer

## Next steps

1. Open the project in Android Studio.
2. Sync Gradle and install the Android SDK components if prompted.
3. Replace the placeholder home screen with a real navigation shell.
4. Connect the app to your Jellyfin server using the PiggieTV API and media endpoints.
